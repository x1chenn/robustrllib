RARL¶

Robust Adversarial Reinforcement Learning

OnlineEnvironment-centricBase · PPO / TRPOClaims · dynamic shift

A two-player zero-sum game against an adversary that applies external forces.

At a glance¶

Property Value
Group Robust Online Algorithms
Setting Online
Family Environment-centric
Base algorithm PPO / TRPO
Claimed robustness Dynamic shift
Shifted-env rollout Yes
Adversarial network Yes
Learned model No
Training budget 2M environment steps
Original paper Pinto et al. Robust Adversarial Reinforcement Learning. ICML, 2017.

Mechanism¶

RARL casts robustness as a two-player zero-sum game. An adversary applies bounded external forces to the robot and is trained to minimise the protagonist's return, and the two are updated in alternating blocks.

The library provides two variants that differ only in the policy optimiser. TRPO appears in the library only as the base of RARL-TRPO.

Run the method¶

python baselines/rarl_hopper/train.py \
    --algo ppo  --env Hopper-v5 --seed 0 --total-steps 2000000
python baselines/rarl_hopper/train.py \
    --algo trpo --env Hopper-v5 --seed 0 --total-steps 2000000
File Path
Implementation baselines/rarl_hopper

Training rollouts come from the method's own perturbed environment. The configuration files are explained in Run a Method, and the evaluation of the frozen checkpoint in Evaluation Protocol.
