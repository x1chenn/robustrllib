PPO¶

Proximal Policy Optimization

OnlineStandard reference

The on-policy reference: a clipped probability-ratio surrogate with GAE.

Features¶

Feature Value
Group Standard Algorithms
Setting Online
Family Standard reference
Base algorithm —
Claimed robustness —
Training budget 2M environment steps
Original paper Schulman et al. Proximal Policy Optimization Algorithms. arXiv:1707.06347, 2017.

Mechanism¶

PPO is the on-policy reference: a clipped probability-ratio surrogate on trajectories from the current policy, with generalised advantage estimation. The library uses the Stable-Baselines3 implementation.

PPO is the backbone of ATLA, ATLA-SA and RARL-PPO.

Run the method¶

python examples/robust_v2/run_experiment.py \
    -c robustrllib/configs/experiment/ppo_hopper.yaml
File Path
Implementation robustrllib.algos (Stable-Baselines3 adapter)
Algorithm card robustrllib/configs/algorithm/ppo_hopper.yaml
Experiment file robustrllib/configs/experiment/ppo_hopper.yaml

Training is on the nominal task. The configuration files are explained in Run a Method, and the evaluation of the frozen checkpoint in Evaluation Protocol.

Robust performance¶

Normalized score of the frozen last checkpoint. Q1 to Q4 are the severity quartiles of each perturbation ladder, ordered by displacement from the nominal setting, and All covers every shifted condition.
