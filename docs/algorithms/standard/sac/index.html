SAC¶

Soft Actor-Critic

OnlineStandard reference

The off-policy reference: twin critics and an entropy-regularised stochastic actor.

Features¶

Feature Value
Group Standard Algorithms
Setting Online
Family Standard reference
Base algorithm —
Claimed robustness —
Training budget 1M environment steps
Original paper Haarnoja et al. Soft Actor-Critic: Off-Policy Maximum Entropy Deep Reinforcement Learning with a Stochastic Actor. ICML, 2018.

Mechanism¶

SAC is the off-policy reference: twin critics with a clipped double-Q target and a stochastic actor whose objective adds an entropy bonus with automatically tuned temperature. The library uses the Stable-Baselines3 implementation.

SAC is the backbone of DR-SAC and RSC-SAC.

Run the method¶

python examples/robust_v2/run_experiment.py \
    -c robustrllib/configs/experiment/sac_hopper.yaml
File Path
Implementation robustrllib.algos (Stable-Baselines3 adapter)
Algorithm card robustrllib/configs/algorithm/sac.yaml
Experiment file robustrllib/configs/experiment/sac_hopper.yaml

Training is on the nominal task. The configuration files are explained in Run a Method, and the evaluation of the frozen checkpoint in Evaluation Protocol.

Robust performance¶

Normalized score of the frozen last checkpoint. Q1 to Q4 are the severity quartiles of each perturbation ladder, ordered by displacement from the nominal setting, and All covers every shifted condition.
